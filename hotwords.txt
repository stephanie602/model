# 包装机场景的命令表。两处用它,而且是同一份:
#
#   命令 KWS(--command-kws)  解码时直接从音频里听这些词。噪声环境下唯一还站得住的
#                            一路 —— 实测同一段录音信噪比 5 dB:ASR 那条 0/2、这条 2/2
#   拼音匹配(intent.py)      ASR 出字之后,把同音错字捞回来("文度"→"温度")
#
# 一行一条,行尾 :数字 是热词权重(只对 transducer 模型有效,SenseVoice 忽略)。
# 井号开头是注释。改完这张表,KWS 和拼音匹配两边同时生效,不用改代码。
#
# 挑词的规矩:
#   · 四个字上下最稳。两个字的("温度")误触发多,六个字以上的 KWS 难听全。
#   · 长句子拆成几个**带实义**的片段。"机器目前温度和速度是什么"拆成
#     目前温度 / 温度和速度 / 速度是什么,听全一个就够,咬掉头尾也不怕。
#   · 别放"今天我们""机器目前"这种没实义的片段:命中之后整句会被替换成
#     这个片段送进 LLM,闲聊里说一句"今天我们要检修"就被截成"今天我们"。
